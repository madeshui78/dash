# dash 使用指南

版本：1.0.14 · Android 7.0 及以上

dash 是一个把「读—记—测—复盘」串成一条线的英语学习工具。它不要求注册账号，所有数据存在手机本地；AI 部分需要你自己的 DeepSeek API Key。

---

## 一、安装与首次启动

### 安装

从 [Releases](https://github.com/madeshui78/dash/releases) 下载 `dash-1.0.14-arm64.apk`，用手机浏览器或文件管理器打开安装。

- 绝大多数 2018 年后的安卓手机选 arm64 版即可。
- 如果提示「应用未安装」或安装后闪退，换通用包再试。
- 系统提示「未知来源应用」时，允许当前浏览器/文件管理器安装。

### 第一次打开

1. 阅读并同意隐私说明（数据只存本地）。
2. 填写 **DeepSeek API Key**：
   - 获取地址：<https://platform.deepseek.com/api_keys>
   - Key 以 `sk-` 开头，长度 20 位以上
   - 没有 Key 无法进入应用；Key 只保存在本机，不会上传
3. 保存后进入打卡页。

> 之后可以在「设置 → DeepSeek API Key」里更换 Key，也可以点「测试连接」确认是否可用。

## 二、界面结构

底部四个页签，从左到右：

| 页签 | 用途 |
| --- | --- |
| 作文 | 每天一篇精读，生成、点词、标记、看译文 |
| 单词 | 单词本、背词、复习、导入导出 |
| 错词本 | 作文标记 + 做题错词，提交复盘 |
| 问答 | 普通 AI 问答 + 固定的「错词复盘」窗口 |

左上角菜单（☰）里还有：添加单词、统计、错词复盘、导出词表、批量导入、打卡记录、错词记录、管理分区、设置。

## 三、每日打卡

打开应用先到打卡页：

- 上方是连续打卡天数、本月记录
- 中间一个按钮，点一下完成今天的打卡
- 打卡后进入主界面

打卡记录在「☰ → 打卡记录」里查看。

---

## 四、作文精读

### 生成一篇

1. 进入「作文」页签。
2. 顶部「生成条件」可以设置：
   - **体裁**：议论、记叙、说明等
   - **内容要求**：例如「人工智能对学习的影响，偏议论」
3. 点「生成一篇」，等 AI 写完。
4. 想换一篇，点右上角「历史」可以回看之前生成过的作文。

### 点词看释义

- 直接点正文里的任意单词，底部会弹出释义卡片。
- 卡片里可以听发音、看词性和中文释义。

### 标记想记的词

1. 点右上角的「标记」按钮，进入标记模式（按钮变红）。
2. 依次点要记的词，词会标红。
3. **连续点几个相邻的词，会合成一条短语**（比如 `that textbooks`）。
4. 再点一次「标记」退出标记模式。

标红的词会自动进入「错词本」，并记下它所在的句子和段落。

### 逐句译文

底部按钮「生成逐句译文」，生成后可以逐句对照；生成过的译文会存下来，下次打开不用重新生成。

### 字号

作文字号在「设置 → 作文字号」里调，范围 14–26。

## 五、单词本

### 添加单词

- 「☰ → 添加单词」：手动输入英文、中文、词性。
- 「☰ → 批量导入」：支持 PDF / Excel / TXT 单词表。导入后按分区归类，可先在「管理分区」里建好分区。

### 背词流程

在「设置 → 学习走哪套流程」里二选一：

- **四步流程**：看词 → 认义 → 拼写 → 听写，一步不漏，适合新词。
- **连续小循环**：一轮少量词，反复滚动，适合一次性啃完一批。

背词时：

- 点卡片看答案
- 「记得」/「忘了」决定这个词下一轮什么时候再出现
- 右上角可以听发音；「设置 → 背单词时自动发音」可以打开自动朗读

### 复习

到复习时间的词会出现在「单词 → 复习」里。一轮结束会显示正确率，可以「再来一轮」。

### 快刷自测

在单词/错词相关页面进入「快刷自测」：

- 一题一词，点「对」或「不对」，立刻给结果和释义
- 「再听一遍」重放发音
- 结束后可以「只刷这 N 个错的」或「错题重刷」

## 六、错词本

错词本汇总两类词：

1. **作文标记**：你在作文里标红的词/短语，带原句和段落
2. **做题错词**：快刷、复习里答错的词

### 回到原文

点一条作文标记，会切到作文页并自动滚到那一段，被点的词用**琥珀底色 + 红色下划线**高亮；短语会按词拆开，每个词都亮。

### 提交今日错词

底部「提交今日错词」：

- 收集**今天**新标的作文词和今天答错的词（最多 30 条）
- 自动清掉短语首尾的 `that` / `and` / `on` 这类虚词
- 切到问答页的「错词复盘」窗口，后台发给 AI，不占用你的聊天记录

---

## 七、错词复盘

### 看复盘

复盘结果是一张结构化卡片：

- 顶部：分组标签（如「词根词缀」「搭配」「拼写」）和词数
- 中间：逐词一行，包含正确释义、记忆法、所属分组
- 底部：三步学习路线

点任意一个词，会弹出全宽详情：单词、朗读、音标（词库有才显示）、分组、释义、记忆法、例句，以及「在复盘里继续问」。

### 右侧词目录

- 屏幕右侧是一列横线，一条线对应一个词
- **点一下**跳到那个词，选中的线会变长变蓝
- **按住上下拖**可以连续切换
- 手动滑动复盘列表时，蓝色长条会跟着滚动进度走，不用手动对齐

### 追问

- 右下角圆形按钮打开悬浮窗，问整次复盘相关的问题
- 从某个词的详情点「在复盘里继续问」，会自动带上这个词，回答围绕它展开
- 追问会按这次复盘归档，在「☰ → 错词记录」里能翻到

### 错词记录

「☰ → 错词记录」按时间列出每次提交：

- 点开可以看到当时发给 AI 的原文
- 下面附「追问记录」，是你和 AI 围绕这次复盘的问答

---

## 八、AI 问答

「问答」页签顶部有两个固定窗口：

- **对话**：普通提问。问单词、问语法、改句子、让 AI 出练习都可以。
- **错词复盘**：只放复盘内容，不混进普通聊天。

普通对话里：

- 你的消息是蓝底白字、右对齐；AI 是白底、左对齐，带「AI」标记
- 长按任意一条可以复制或删除
- 右上角「历史」切换会话，「＋」新建对话

> 复盘窗口的追问不会写进普通对话，两边互不干扰。

## 九、设置

| 设置项 | 说明 |
| --- | --- |
| DeepSeek API Key | 更换 Key，可测试连接 |
| 模型 | 默认 `deepseek-chat` |
| 朗读语速 | 0.5×–1.5× |
| 背单词时自动发音 | 每个词自动读一遍 |
| 作文字号 | 14–26 |
| 每天自动抽几个新词 | 1 以上整数 |
| 学习走哪套流程 | 四步流程 / 连续小循环 |
| 我的背景 | AI 造例句时会参考，例如「计算机网络专业，准备专升本」 |
| 数据备份 | 导出/导入备份文件，换手机迁移 |

### 备份与迁移

1. 「☰ → 设置 → 导出备份」，得到一份备份文件。
2. 传到新手机（网盘、聊天工具均可）。
3. 新手机装好 dash，进「设置 → 导入备份」，选择该文件。

备份包含单词、作文、标记、错词、对话和复盘记录；**不包含** API Key，换机后需要重新填一次。

## 十、数据与隐私

- 不注册账号，不上传学习数据。
- 作文、单词、标记、对话、复盘记录全部存在手机本地 SQLite 数据库。
- API Key 只存本机，仅用于直连 `api.deepseek.com`。
- 卸载应用会清空本地数据，卸载前先导出备份。

## 十一、常见问题

**Q：打开只看到 Key 页面，进不去？**
A：说明本机没有可用的 Key。填一个 `sk-` 开头的 Key 并保存；没有 Key 只能退出应用，去 <https://platform.deepseek.com/api_keys> 获取。

**Q：提示「连接失败」？**
A：先检查网络，再点「设置 → 测试连接」。Key 失效、欠费、网络被拦都会失败；换网络或重新生成 Key 再试。

**Q：生成长时间没反应？**
A：作文生成和复盘都要几十秒。网络差时会更久；如果超过两分钟，退回重试一次。

**Q：复盘一直显示「正在整理错词…」？**
A：多半是网络或 Key 的问题。切到「对话」发一句「你好」，能正常回就说明 Key 没问题；不能回就去设置里测一下连接。

**Q：点了标记词，作文里没高亮？**
A：先确认这篇作文没有被重新生成过（旧标记可能找不到原文，会提示「标记保留但找不到原文」）。仍不行就退出重进一次。

**Q：朗读没声音？**
A：检查系统媒体音量和「设置 → 背单词时自动发音」；部分机型需要在系统设置里给 dash 安装英文 TTS 语音包。

**Q：换手机后数据没了？**
A：dash 不联网同步。旧手机先「导出备份」，新手机「导入备份」。

**Q：能同时装两个版本吗？**
A：不能。包名相同，安装新包会覆盖旧包；数据会保留，但签名不同的包无法覆盖安装，需要先卸载（卸载前务必备份）。
